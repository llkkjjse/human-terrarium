# 人类生态箱（Human Terrarium）

一个在本地电脑运行、由 DeepSeek 驱动的社会生态模拟游戏。你先用自然语言描述社会，再观察 24 名拥有不同阶级、性格、职责、能力和资产的居民如何生活、交流、合作、犯罪、受伤并应对政策。

> 当前版本需要 DeepSeek API 才能生成社会、编译政策和推进 AI 时间帧。项目不会用伪随机结果冒充离线 AI；AI 请求失败时，本帧不会提交，游戏时间也不会前进。

## 目前可以做什么

- 用自然语言和参数创建社会，默认生成 24 名居民。
- 每位居民具有 D&D 风格的六项能力：力量、敏捷、体质、智力、感知、魅力。
- 阶级、现金、收入、住房、车辆、外观财富和他人眼中的阶级彼此独立。
- 居民拥有职责、日常需求、关系、知识、记忆、健康、法律状态和个人计划。
- 用自然语言制定社会政策，DeepSeek 将其编译为可执行的本地规则。
- 为单个居民填写“特殊特性”和玩家目标。优先级为：**特殊特性 > 单人目标 > 社会政策 > 日常行为**。
- 为某位居民安排必然发生的强制事件；AI 只负责翻译，事件由本地规则强制执行。
- 居民只有在实际同区接触时才能形成对话记录，并会通过对话传播知识与八卦。
- 本地规则负责经济、健康、犯罪、证据和执法结算，AI 负责提出每帧意图。
- 可选择“1 小时”“半天”“1 天”推进，也可连续运行或快速观察。
- 观察某位居民时，可查看其完整生活史、对话、关系、知识、资产和法律记录。
- 拖动速度或粒度控件不会制造时间线事件；全局时间线只保留有意义的因果事件。

## 快速启动

### 1. 环境要求

- Node.js 20.19+ 或 22.12+
- npm
- DeepSeek API Key
- 现代浏览器（推荐 Edge 或 Chrome）

### 2. 下载并安装

~~~powershell
git clone https://github.com/llkkjjse/human-terrarium.git
cd human-terrarium
npm install
Copy-Item .env.example .env.local
~~~

macOS / Linux 可使用：

~~~bash
cp .env.example .env.local
~~~

### 3. 配置 DeepSeek

编辑 .env.local：

~~~env
DEEPSEEK_API_KEY=你的_API_Key
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_GATEWAY_PORT=8787
~~~

API Key 只由本机网关读取，不会打包进浏览器代码，也不要把 .env.local 提交到 GitHub。

### 4. 启动

~~~powershell
npm run dev
~~~

这个命令会同时启动：

- 网页前端：通常是 <http://localhost:5173>
- 本地 AI 网关：<http://127.0.0.1:8787>

终端显示 “Human Terrarium is ready” 后，打开终端给出的网页地址即可。

## 基本玩法

1. 输入社会描述，例如“阶级差距明显、邻里爱聊八卦、治安严格的港口社区”。
2. 调整社会参数并生成社会，检查 24 名居民后确认进入。
3. 选择居民，编辑其特殊特性、目标或六项能力。
4. 输入自然语言政策并正式实施；政策会从下一帧开始参与结算。
5. 选择“1 小时”“半天”或“1 天”，推进一帧或连续运行。
6. 打开居民详情，在“永久生活史”和“完整对话”中观察其经历。

单人干预优先于全社会规则，但不保证任务一定成功。例如，身无分文的居民可能根据自身优势选择劳动、诈骗或抢劫；结果仍取决于目标是否有钱、证据、目击、治安人员和后续执法。

## AI 调用与负担

- 24 名居民共享一次帧请求，不会为每个人分别调用一次 API。
- 只给当前选中的居民发送额外详情，其他居民使用压缩上下文。
- 完整历史、地图坐标和 API Key 不会放入帧提示词。
- 创建社会、编译政策、解析强制事件按需调用。
- 界面会显示最近一次调用的耗时、Token 数和估算费用。
- AI 超时或返回非法数据时，当前帧保持未提交，可直接点击“重试当前帧”。

粒度越大，调用次数越少，但每次跨越的生活时间更多。想细看一个人时用“1 小时”；长期观察可用“半天”或“1 天”。

## 保存、隐私与数据

- 世界状态和完整历史使用浏览器 IndexedDB 自动永久保存，没有自动裁剪。
- 刷新页面或重新启动开发服务器后会恢复最近世界。
- 当前版本没有云同步，也没有图形化导出按钮。
- 清除站点数据、浏览器存储或卸载对应浏览器配置会删除存档；重要存档请先备份浏览器数据目录。
- 推进 AI 帧时，压缩后的社会和居民状态会通过本机网关发送给 DeepSeek；请不要在社会描述、政策、目标或特性中填写隐私信息。

~~~powershell

npm run dev:web      # 只启动前端（不能正常推进真实 AI 帧）
~~~

## 项目结构

~~~text
src/
  ai/            AI 协议、上下文压缩与浏览器客户端
  api/           帧控制器和运行时 API
  game/          Phaser 地图和居民可视化
  persistence/   IndexedDB 存档与永久历史
  sim/           社会模型、生成器和本地规则解析器
  ui/            React 控制面板、人物观察与时间线
server/          本地 DeepSeek 网关
tests/           单元、集成和端到端测试
~~~

核心流程：

~~~text
玩家命令 -> 本地准备帧 -> DeepSeek 提议居民行动
         -> 本地规则验证与结算 -> 原子保存世界和历史 -> 更新画面
~~~

DeepSeek 不能直接修改存档。所有响应都必须通过结构校验、优先级校验和本地因果规则后才能提交。

## 常见问题

### 提示缺少 DEEPSEEK_API_KEY

确认项目根目录存在 .env.local，变量名拼写正确，然后重启 npm run dev。

### 页面能打开，但 AI 请求返回 502 / 504

检查网络、API 余额、Key 和 DEEPSEEK_BASE_URL。失败帧不会推进时间，恢复后可重试。

### 端口被占用

关闭占用 5173 或 8787 的进程，或修改 Vite / .env.local 中的端口配置。

### 端到端测试找不到浏览器

~~~powershell
npx playwright install
~~~
